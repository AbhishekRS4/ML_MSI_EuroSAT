# A repo with Ray distributed ML experiments on EuroSAT multi-spectral imagery dataset


## Experiments
* The goal of the project is to perform supervised learning - classification experiments for studying the effects of using different data bands from Multi Spectral Imagery (MSI) on the LULC classification model performance. The goal is to train models using data on the disk and explore distributed training on streaming data from huggingface using Ray without downloading the data to the disk.
