# A repo with experiments on EuroSAT multi-spectral imagery dataset


## Experiments
* The aim of this repo is two-fold
* Firstly, perform supervised learning experiments for studying the effects of using different 
data bands from Multi Spectral Imagery (MSI) on the LULC classification model performance. 
The goal is to train models which are physics aware.
* Secondly, train a model using SSL method and compare the model performance, which is SSL pretrained, 
which can be useful for smaller labeled dataset.
